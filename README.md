# TLE Stalker

A web-based tool that helps track your progress on the [TLE Problem Sheet](https://www.tle-eliminators.com/cp-sheet) by analyzing your Codeforces submissions.

🔗 **[Try it live here!](https://paramveer5404.github.io/TLE_Stalker/)**

## Description

TLE Stalker is a simple interface that leverages the Codeforces API to:
- Retrieve your last 10000 submissions from Codeforces
- Match them against problems from the TLE Problem Sheet
- Provide a quick overview of your progress and remaining challenges

The problems from the TLE sheet are maintained in a dictionary within the application for efficient lookup and matching.

## Features

- Real-time submission tracking
- Easy-to-use interface
- Quick progress overview
- Integration with Codeforces API
- Focused tracking of TLE sheet problems
